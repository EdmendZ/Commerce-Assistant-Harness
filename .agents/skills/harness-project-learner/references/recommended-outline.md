## 前置知识的处理

只在当前阅读确实受阻时补充 FastAPI 路由、依赖注入、async/await、SQLAlchemy 事务或 LangChain 工具调用的必要知识，再立即回到项目。B02 是完整链路预览，不要求提前掌握 B03–B08 的实现细节。用户想提前运行项目时，可以先读 B08 的启动小节，再回原位置。

## 两条路线如何切换

- “Day04 学完，切你的顺序”：根据实际答题证据保留轮次领取、输入版本等掌握记录；确认 B01/B02 的基础是否已有，再定位尚未掌握的 B 章节。不能仅凭“学完 Day04”推断整个 B06 已掌握。
- “B04 学过，回 Day09”：工具契约、上下文等已掌握部分简短回顾，只补原课中的遗漏小节；不重复整章，也不自动完成 Day11。
- “直接学动态 Skill”：定位 B04 的技能小节 / Day11 的动态路由，不要求用户先选路线或通过所有前置测验。保留先前路线位置，单点问答结束后可返回。

共享进度按具体知识点记录，例如消息幂等、输入版本、工具契约、Skill 范围、事实校验、Outbox、人工接单。Day/B 编号只描述学习位置；涉及多个知识点的章节是否完成，需分别依据理解或练习记录判断。
